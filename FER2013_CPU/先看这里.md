## 本地识别一张图片

解压并进入本目录，使用 Python 3.11 或 3.12。终端执行：

```bash
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python setup_weights.py
python predict.py --image face.png
```

`face.png` 是已裁剪的人脸。程序输出七类表情及其置信概率。包内包含本次派生的权重，`setup_weights.py` 会从发布方补齐其余公开权重并校验 SHA-256。AffectLens 权重限非商业研究、教学与演示。训练数据权利与各模型许可见其原始发布条款。

## 复核准确率

准备原始 FER2013 CSV 后执行：

```bash
python -m fer.data --source fer2013.csv --out data/prepared
python verify_result.py --data data/prepared
```

如果没有 CSV，可以运行 `python -m fer.fetch_public_data --out data/raw` 下载固定版本的公开镜像，再用 `data/raw/fer2013.csv` 替换命令里的 CSV 路径。`verify_result.py` 核对样本 ID、原标签及像素哈希，并以缓存中实际模型输出重算分数。

课程报告中注明所用公开权重、量化和融合方法，以及 AI 协助生成代码与评测材料。
